# ApexCrew v0.1 Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Execute this plan task-by-task with a fresh spec-compliance check and quality check after each task.

**Goal:** Close the shortest deterministic v0.1 loop from real Worker repair through one final target-ref CAS, retention cleanup, and same-revision release evidence.
